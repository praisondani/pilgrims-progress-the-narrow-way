# Release Roadmap

Milestones run sequentially. Every milestone must keep local gameplay working, pass unit/build/browser checks, update `GAME_STATUS.md`, and push a focused commit to `main`.

## 1. Quality foundation

- Visibility presets and readable baseline lighting
- Split production bundles and enforce size budgets
- Desktop/mobile browser smoke tests
- GitHub Actions quality gate

## 2. Cross vertical-slice production pass

- Tune all 52 beats for pacing, navigation, contrast, and puzzle clarity
- Add scene-specific environment transitions and fail-safe checkpoints
- Add settings for subtitles, reduced motion, camera sensitivity, and text size
- Verify complete Dream-to-Cross run on desktop and mobile

## 3. Road through Palace Beautiful

- Simple, Sloth, Presumption, Formalist, Hypocrisy
- Hill Difficulty, lost roll, Timorous and Mistrust
- Palace Beautiful characters, study, armory, and rest

## 4. Valleys and Vanity Fair

- Apollyon encounter focused on courage and defense
- Valley of Shadow traversal and sound-based navigation
- Faithful, Talkative, Evangelist warning
- Vanity Fair exploration, trial, Faithful’s witness, Hopeful joining

## 5. Doubting Castle through Beulah

- By-Ends, Demas, By-Path Meadow, Giant Despair
- Delectable Mountains, Ignorance, Little-Faith
- Flatterer, Atheist, Enchanted Ground, Beulah

## 6. River and Celestial City

- Distinct Christian and Hopeful river experiences
- Final ascent, gate verification, transformed-city ending
- Credits, full journey recap, new-game-plus study mode

## 7. Art and audio production

- Consistent hero-quality character silhouettes and animation
- Final environment dressing, particles, lighting, camera rails
- Original score, ambience, effects, and optional voice pipeline
- Asset license/source inventory

## 8. Release hardening

- Save migrations and corruption recovery
- Accessibility audit and keyboard/touch/controller QA
- Performance presets and low-end mobile profiling
- Offline shell, deployment, error reporting, browser matrix, release checklist

## Release acceptance

- First-time player completes Christian’s full Part One journey without developer intervention
- Story remains understandable without prior book knowledge
- All symbolic mechanics communicate their meaning through play and journal context
- Desktop and mobile controls, save/resume, accessibility, and low-quality mode work
- CI, browser tests, bundle budgets, and production build remain green
